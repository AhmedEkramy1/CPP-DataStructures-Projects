## 🏦 Project 1: Bank Management System

A robust console-based application built with **C++** that simulates real-world banking operations using Object-Oriented Programming (OOP) and standard library containers.

### 🌟 Features
* **Account Management:** Create unique bank accounts with auto-validation.
* **Transactions:** Deposit and withdraw funds with balance checks.
* **Data Organization:** View all active accounts dynamically.
* **Data Security:** Encapsulated member variables protecting sensitive user data.

### 🛠️ Concepts & Technologies Applied
* **Object-Oriented Programming (OOP):** Encapsulation, Classes, and Objects.
* **Standard Template Library (STL):** `std::vector` for dynamic storage and `std::string`.
* **Memory Management:** Pointers and Const Methods for clean and efficient execution.
